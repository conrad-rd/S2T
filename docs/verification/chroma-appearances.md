ChromaPreset ports the field formulas and 16-step Bezier inversion from `Resources/Glow.metal`. ChromaAppearance uses its linear-light palette and Box corner-color interpolation, the generated fields, and MPS Gaussian effect blur from GlowRenderer. Box's separate field blur uses the original `230.9 / 3 * scale * spread` calibration, followed by power 2.6. Effect blur runs before color falloff. Native background blur uses the separate map. The intensity slider reaches the reference at 1.3, with the existing speech brightness variation and audio-dependent native blur. Silence and processing turn native blur off.

S2T adapts the geometry to its job. Bottom attaches to the current display's lower edge and reserves room for the source field plus four effect-blur sigmas. Around Input follows the detected field and retains its capsule or continuous corners. Its color coordinates fit the original Box colors to that field. Distance follows the actual native path, so the thin sweep and clipped color boundary agree at the corners. That boundary replaces the demo's expanded solid Box edge; the sweep starts there without adding the demo's interior stroke offset. It never fills or blurs the text interior, even though the Chroma demo can draw a solid Box surface. Around Notch uses the display's real housing or centered fallback and preserves fading wings. Position and scale metadata do not override focused-field or physical-notch targeting. The new drawing bounds contain the longer tails.

Canvas draws cached generated tint, additive light and sweep images in linear color mode. Speech transforms the existing diffuse color and native fields together, while the sweep stays attached to the boundary. Reduce Motion freezes those transforms. The existing processing indicators remain separate. No generated fields read desktop content.

Desktop composition remains S2T's native WindowServer-aware progressive Gaussian blur. Chroma Glow's screen capture and hexagonal desktop-sampling shader are not used. The exported quality value remains in the preset; native macOS composition supplies its own sampling quality. Canvas tint and additive blending approximate Chroma's captured-background compositing on the native blurred desktop. This is a source-based adaptation with exact preset values, not a claim of pixel-identical rendering or cross-app visual verification.

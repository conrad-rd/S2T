# Settings sidebar

The current design is an 88-point icon rail, reduced from 208 points. It preserves the existing Appearance, Models and API keys destinations and Dictation group divider. Custom Apple-inspired vector icons use a shared 24-point grid and 1.8-point rounded strokes. Editable SVGs and the state reference sheet are in docs/design/sidebar-icons. Both SVG and native artwork use SidebarGlyph's geometry.

Tiles are always square, centered within each row. Idle outlines use a subtle vertical gradient from 25 percent white at the top to 19 percent at the bottom.
